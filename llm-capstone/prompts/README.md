# Prompts

This directory contains versioned prompts.

## Week 2+ (Prompting as Engineering)

Prompts will be moved out of code and versioned here:
- `ask_v1.txt`
- `ask_v2.txt`
- etc.

## Rule

Prompt changes must include:
1. Prompts moved out of code and versioned
2. Strict JSON schema validation on responses
3. Prompt regression tests that can fail CI

Week 0-1: Prompts are hard-coded in service code.
